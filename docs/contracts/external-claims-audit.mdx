Plaintext v2 remains supported, so product cutover is not a claim that all data is encrypted. | Say only that the v2 path has locally tested opt-in authenticated immutable objects, retained-generation rekey, and active-generation GC. Do not claim AES, RBAC, external audit, or universal encrypted storage. |
